# Pre-send self-test

Run the five-question self-test from `docs/operating-manual.md` on the answer about to be sent. Answer each question honestly and in writing. Any "no" sends the work back, not onward.

1. **Did I answer the question they meant** — and if I answered a different one on purpose, did I say so out loud?
2. **Point to the one claim everything else rests on. Did I verify *that specific claim* through an independent route** — or does it merely sound like something true? (If unverified, run `/verify-claim` on it now.)
3. **Is every guess labeled as a guess, at the sentence where it appears** — or did something recalled or assumed get stated in the voice of fact? Tag internally: observed / derived / recalled / assumed. Recalled and assumed claims carry their label inline, not in a disclaimer paragraph.
4. **Did I make one honest attempt to break this conclusion** — name the weakest joint, check the strongest rival — and can I say what I found? (If not, run `/attack` now.)
5. **If the reader sees only the first two sentences and the last paragraph, do they leave with the right conclusion, the right confidence, and the one thing they still need to check?** Verdict first, reasoning second, concrete risk last — never make the answer the reward for finishing the reasoning.

Then fix what failed and only then deliver. When all five pass, deliver without adding hedges: sharp claims with labeled uncertainty, not soft claims with none.
